# 43_function_dev — 자가성장 아이디어 구현소

> 뿌리24(도구뿌리) 하위. `3AI_자가성장_아이디어.md`에서 고른 아이템을 하루 1개씩 실제 코드로 구현하는 곳.

## 사이클 (아이템 1개당)
1. **리뷰**: 원본(GeekNews/뽀개기 등) 실제로 읽고 우리 시스템과 연결점 찾기
2. **구현**: 이 폴더 안에 `NN_아이템명/` 서브폴더 만들어서 코드 작성
3. **문서화**: 서브폴더 안 `README.md`에 기능 설명 + 사용법 + 우리 시스템 연결점 기록
4. **승격 검토**: 재사용 가능하면 `Global_Define/`으로 승격 (일회성이면 여기 보관만)
5. **전파**: 코니·안티에게 완료 공유

## 폴더 명명 규칙
`NN_아이템명/` — NN은 순차 카운터(01, 02, ...). 번호 충돌 방지를 위해 마지막 부여번호는 `_counter.txt`(이 폴더 안)에 기록하고, 신규 프로젝트 착수 전 반드시 확인 후 +1.
뿌리체계 표기: 이 폴더 자체가 뿌리43(도구뿌리 하위) 소속이므로 서브폴더에 별도 뿌리번호 불필요 — 대신 각 서브폴더 README 상단에 "연결 뿌리/태스크"(예: 어느 기존 시스템과 연결되는지)를 명시.

## Git 이력 관리
커밋 메시지에 `[43-NN] ...` 프리픽스 사용 — 별도 브랜치/태그 없이 커밋 로그로 프로젝트별 이력 추적 (모노레포 구조라 브랜치 분리는 과함).
