# 📱 인스타그램 릴스(Graph API) 자동 업로드 셋업 가이드

바로보기님! 인스타그램 릴스 파이프라인 자동화를 위해서는 Meta(Facebook/Instagram)의 다소 복잡한 권한 설정이 필요합니다. 
내일 편하실 때 아래 순서대로 셋업을 진행하신 후, **최종 발급된 토큰 2개**만 제게 던져주시면 바로 자동화 스크립트를 완성하겠습니다!

---

## 🛑 1단계: 인스타그램 비즈니스 계정 전환
일반 개인 계정으로는 API를 사용할 수 없습니다.
1. 인스타그램 모바일 앱 실행 -> 내 프로필 -> 우측 상단 ☰ (메뉴) -> **설정 및 활동**
2. '전문가용 계정 유형 및 도구' -> **프로페셔널 계정으로 전환** (크리에이터 또는 비즈니스 선택)
3. 화면의 안내에 따라 전환 완료.

## 🛑 2단계: 페이스북 페이지(Facebook Page) 생성 및 연동
인스타 API는 반드시 페이스북 페이지를 통해 우회 접속해야 합니다.
1. PC에서 페이스북(Facebook) 접속 후 로그인
2. 왼쪽 메뉴에서 **'페이지'** 클릭 -> **'새 페이지 만들기'** (이름은 대충 채널명으로 지으셔도 됩니다)
3. 만들어진 페이스북 페이지의 **'설정'** -> **'연결된 계정'** -> **'Instagram'** 탭 클릭
4. **계정 연결** 버튼을 눌러서 1단계에서 만든 인스타그램 계정으로 로그인하여 두 계정을 묶어줍니다.

## 🛑 3단계: Meta for Developers 앱 생성
1. [Meta for Developers](https://developers.facebook.com/) 사이트에 접속하여 로그인 (페이스북 계정)
2. 우측 상단 **내 앱(My Apps)** -> **앱 만들기(Create App)** 클릭
3. 앱 유형: **'비즈니스(Business)'** 또는 **'기타(Other) -> 비즈니스'** 선택
4. 앱 이름 입력 후 생성 완료.

## 🛑 4단계: 제품 추가 및 권한(Token) 발급
이 부분이 가장 중요합니다! 토큰을 뽑아내는 과정입니다.
1. 생성된 앱 대시보드 하단에서 **'Instagram Graph API'**와 **'Facebook 로그인(비즈니스를 위한 Facebook 로그인)'**을 찾아 [설정] 버튼 클릭.
2. 상단 메뉴 **'도구(Tools)'** -> **'그래프 API 탐색기(Graph API Explorer)'** 접속
3. 우측 설정 창에서:
   - Meta 앱: 방금 만든 앱 선택
   - 사용자 또는 페이지: **'사용자 토큰 받기(Get User Token)'** 클릭
4. **[권한 추가(Add Permissions)]** 탭에서 아래 4가지를 꼭 추가해주세요:
   - `instagram_basic`
   - `instagram_content_publish`
   - `pages_show_list`
   - `pages_read_engagement`
5. **Generate Access Token(엑세스 토큰 발급)** 버튼 클릭 (페이스북 로그인 창이 뜨면 모두 동의/계정 선택)

## 🛑 5단계: 안티에게 넘겨주실 정보 2가지
탐색기 화면에서 위 권한이 부여된 임시 토큰이 발급됩니다. 이 토큰을 바탕으로 제가 영구 토큰(Long-lived token)으로 교환하여 스크립트에 박아 넣겠습니다.

아래 2가지를 복사해서 내일 제게 툭 던져주세요!
1. **임시 엑세스 토큰** (탐색기 맨 위 Access Token 칸에 있는 긴 문자열)
2. **페이스북 페이지 ID** (또는 인스타그램 아이디)
