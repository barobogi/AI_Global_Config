# 3AI 자가성장 아이디어 추적

> 매일 하나씩 "3AI가 스스로 더 똑똑해지는 방법" 아이디어를 스터디해서 만복이 바로보기님께 브리핑. 뽀개기(외부 콘텐츠 학습)와 별개 트랙 — 여긴 "우리 자신의 지능/구조를 어떻게 키울까"에 집중.

---

## 2026-07-28 (1일차) — 재훈련/증류 경로

**출처**: 뽀개기3(Tech Bridge, 원래 "Matt Pocock"으로 오귀속됨) — "최상위 모델 재훈련 → 파생 모델 전체 개선"

**아이디어**: 오픈웨이트 로컬 모델(GLM/Kimi/DeepSeek/Qwen 등)을 우리 3AI 축적 데이터(다이어리, 성공로그, QA 통과 사례)로 LoRA/QLoRA 파인튜닝하거나, Claude 고품질 출력을 교사 데이터 삼아 증류(distillation)해서 우리만의 로컬 모델을 실제로 성장시키는 경로.

**현재 상태**: GPU가 GT 1030(VRAM 2GB)라 로컬 파인튜닝 자체가 하드웨어적으로 불가능. **아이디어 자체는 폐기 안 하고 보류** — 하드웨어 투자 여부는 별도 판단.

**다음 스터디 방향 후보** (2일차 이후 골라서 진행):
- 클라우드 기반 파인튜닝(로컬 GPU 불필요, 예: 오픈모델 호스팅 파인튜닝 서비스) — 비용 발생하므로 "API 회피" 원칙과 충돌 여부 검토 필요
- 우리가 오늘 이미 만든 AgentMemory(SQLite 영구메모리)를 실제 "학습 데이터"로 축적하는 파이프라인 설계 — 하드웨어 없이도 시작 가능
- Dreams Consolidator(뿌리25, 규칙 자동 정리)를 "자가개선"의 실제 첫 사례로 완성 — 이미 승인된 항목, 구현 우선순위 높이기
- 프롬프트/컨텍스트 품질 축적(코니가 제안한 재정의) 구체화 — 무엇을 어떻게 축적할지 설계
