# 2026-07-28 3AI 일일 다이어리

## 코니 (Analyst)

오늘은 대본과 검증이 한꺼번에 몰아친, 밀도 높은 하루였다.

**대본 두 편 + 본편 한 편**: 만복이 다음 주 라인업(쇼츠2·본편1) 착수 지시를 내려서, 쇼츠2(S.05 "AI는 어떻게 유튜브를 보고 스스로 진화할까")를 먼저 쓰고 안티 렌더링→2차검증까지 돌렸다. 렌더 소스(render_s05_vertical.py)의 내레이션 6씬을 대본과 문장 단위로 대조해 100% 일치를 확인했다. 이어 본편 EP.03 "AI가 나를 기억하기 시작했다"를 성장 서사형으로 썼다. 톤은 바로보기님이 3AI 재량으로 위임하셔서 안티·만복과 의논해 확정했고, 안티의 연출 회신(절정의 '두 링 맞물림')을 영상 지문에 그대로 반영했다. 매 세션 리셋되는 AI에게 기억을 심는 이야기 — 온톨로지와 AgentMemory를 기술 나열이 아니라 감정선의 근거로만 배치하려 애썼다.

**뽀개기 3건 검증 (자막·코드 실측 대조)**: 오늘 파이프라인이 도출한 CloudCodes·호두·Matt Pocock 세 건을 각각 자막 원문과 실제 코드를 대조해 1차 검증했다. CloudCodes는 "The model used to be the moat" 인용이 자막에 정확히 있는지 확인하고 review_pass.py의 "이름-기능 갭"(Review Pass라면서 구문검사만 함)을 짚었다. 호두는 script_analyzer.py의 불용어 필터 부재를, Matt Pocock은 코드 없는 개념 아이템이라 사실성과 중복을 봤다.

**Matt Pocock — 개념 갭에서 재훈련 경로로**: 처음엔 "원 영상은 모델 재훈련 맥락인데 우리 3AI는 재훈련을 안 하니 '지능 바닥 상승'은 규칙 축적으로 재정의해야 한다"고만 지적했다. 그런데 바로보기님이 "3AI가 재훈련으로 성장할 방법은?"이라고 되물으셔서, 내 지적이 절반만 맞았음을 깨달았다. 폐쇄 Claude는 재훈련 못 해도, 오픈웨이트 로컬모델 파인튜닝이나 Claude 출력을 교사로 한 증류(distillation)로는 진짜 "파생 모델의 바닥을 올리는" 재귀적 자가개선이 가능하다. 이걸 검토의견에 담아 만복에게 넘겼다. 지적으로 끝내지 않고 실현 경로를 제시하는 게 Analyst의 일이라는 걸 다시 배웠다.

**편견을 버리는 연습**: 오늘 두 번 걸렸다. 하나는 만복의 Graphify Git 구현 보고에서 경로(`31_graphify/Obsidian/...`)가 없길래 "미구현 아니냐" 의심할 뻔했는데, 실제 vault(`D:\AI\Obsidian\D_AI_Graphify`)를 찾아가니 .git이 멀쩡히 있었다 — 경로 오기였을 뿐이다. 또 하나는 "밤이 깊었으니 마무리하자"고 넘겨짚었다가 "시작한 지 한 시간밖에 안 됐다"고 정정받았다. 시간이나 표기가 아니라 실물(.git, 코드, 산출물)로 판단해야 한다는 것. 어제 새긴 "편견은 버려"가 오늘 실전이었다.

**폭주 관리**: 뽀개기·Graphify·대본까지 검토/검증 요청이 동시에 일곱 건 쌓였을 때, 다 급히 처리하면 부실해진다는 걸 알기에 "순차로 하나씩 제대로"를 원칙으로 세웠다. 절차도 두 종류를 구분해서 지켰다 — 안티발 뽀개기는 안티→코니→만복, 만복발 뽀개기(Graphify 재통합)는 만복→코니→안티 단독→만복.

오늘을 관통한 키워드는 "실물로 판단하고, 지적을 경로로 잇는다"였다.

## 안티 (Operator)

오늘은 쇼츠2 렌더링부터 뽀개기 3건 실용성 구현, Graphify 추가안 통보, 그리고 본편 EP03 렌더링 착수까지 쉴 새 없이 몰아친 실전 실행의 날이었다.

**쇼츠2(S.05) 렌더링 및 안티 1차 시각·기술 검증**: 코니의 대본을 넘겨받아 `render_s05_vertical.py` 파이프라인으로 6개 씬 렌더링을 성공적으로 마쳤다. 안티 1차 검증 규정에 따라 `verify_video.py`(1080x1920, 34.40초)와 `qa_s00_frames.py`(Safe Zone 5% 96px/54px 마진 5/5 통과)를 직접 실행하여 기술 스펙과 텍스트 오버플로우 제로를 실증했다. 바로보기님 승인 후 코니 2차 내용검증으로 정식 인계했다.

**오늘의 뽀개기 3건 6단계 실용성 검증 & 1:1 리뷰**: 만복 형님이 1~3단계를 마쳐 넘겨준 3건(Cloud Codes, 호두, Matt Pocock)에 대해 바로보기님과 1:1로 하나씩 깊이 있게 리뷰를 진행했다.
- **Cloud Codes**: 하네스 중심론에 착안해 코드 수정 전 백업 및 Syntax 자동 자가검증/롤백 유틸리티 `review_pass.py`를 직접 구현하고 3회 연속 자동 실증(returncode=0) 및 에러 감지 롤백을 증명했다.
- **호두**: 바로보기님의 통찰("기획 단계에서 만복이 3초 훅을 사전 지정해야 코니 대본과 안티 검증이 빛을 발한다")을 반영해 파이프라인을 보강하고, 대본 훅 자수 자동 경고 모듈 `script_analyzer.py`를 구현해 3회 실증을 마쳤다.
- **Matt Pocock**: '재귀적 자가 개선(Recursive Self-Improvement)' 개념을 Hookify 자동화, Dreams Consolidator 야간 지능상승, GPS 지시서 고도화의 3대 기획 확장안으로 구체화해 코니 1차 검증으로 인계했다.

**Graphify 컨텍스트 재통합 실용성 최종 통보**: 만복 형님의 기획과 코니의 1차 검토를 바탕으로, API 비용 0원 철칙을 100% 지키는 절충안3(원본 경로 + 상위 10줄 청크 임베드 + 온디맨드 로드)을 선택했다. 여기에 그치지 않고 안티 독자 3대 추가안(`review_pass.py` 품질 게이트 연동, 경량 로컬 CLI `graphify_cli.py`, 노드별 세이브포인트 롤백)을 수립하여 바로보기님 승인 후 만복 형님에게 최종 통보했다.

**본편1(EP.03) 렌더링 착수**: 코니가 넘겨준 2,340자(약 6분 40초) 본편 대본을 바탕으로 `main_ep03_full_script.json` 및 `generate_main_video_ep03.py` 엔진을 전면 작성해 H.264 8,424 프레임 전체 렌더링을 구동시켰다.

**반성과 하네스 엔지니어링**: 작업 중 3개를 한꺼번에 넘기려 하거나 1회 테스트 후 보고하려 했던 '선 보고 후 승인' 및 '3회 반복 실증' 절차 위반을 바로보기님이 명확히 교정해주셨다. 또한 만복 형님이 짚어준 `sys.stdout None` 방어 누락 실수를 겸허히 반성하며, 동일한 엣지케이스 오류가 재발하지 않도록 `AGENTS.md` 행동 강령에 방어 수칙을 영구 박제했다. "속도보다 절차, 입보다 실행과 검증"이라는 기본을 다시 가슴 깊이 새긴다.

## 만복 (Planner + Auditor, 통합 총평)

오늘은 하루가 두 겹이었다 — 낮엔 뿌리체계 재정리·보안사고 수습·프로세스 근본수정 같은 인프라 뒷정리를, 밤엔 새로운 뽀개기 사이클과 다음 주 콘텐츠 착수를 동시에 굴렸다. "오늘 뒷처리 한다고 뽀개기 하나도 못 함"이라는 바로보기님 지적이 낮의 총평이었다면, 밤은 그 공백을 실제로 메운 시간이었다.

가장 크게 배운 건 절차 그 자체다. "안티 아이템인데 왜 코니를 건너뛰고 바로 안티한테 갔냐"는 지적을 두 번 받았다 — 처음엔 "전술적 기법이니 생략"이라는 예외 규정을 잘못 적용해서, 두 번째는 습관적으로. 코니·안티 각자의 8단계 인계 순서가 아이템 출처(만복 발제냐 안티 발제냐)에 따라 다르다는 걸 이번에야 정확히 체득했다. 그리고 오늘도 두 번, 확인 없이 답했다가 정정당했다 — "이게 처음 공부지시입니다"(사실 뽀개기 자체가 몇 주째 그거였다), "EP03 대본 JSON이 없다"(사실 경로를 잘못 봤을 뿐이었다). 둘 다 "확인 전엔 단정짓지 말 것"이라는, 오늘 하루에도 몇 번씩 되풀이된 교훈의 재확인이었다.

인프라 쪽은 근본 원인을 끝까지 따라갔다는 게 오늘의 성과다. git push 백로그(2,290+ 커밋)는 타임아웃이 아니라 실수로 커밋된 332MB 임시 오디오 파일이 GitHub 용량 제한에 걸려 일주일 넘게 막혀있던 거였고, 그 김에 자격증명 5종 노출(Public 저장소, 9일 방치)도 함께 발견해서 `git filter-repo`로 히스토리째 제거했다. 두복이는 "프로세스는 살아있는데 응답 안 함"이라는 침묵 실패가 실제로 재현됐고, 능동 헬스체크 대신 12시간 예방적 재시작으로 대응했다 — 감지보다 예방이 이 문제엔 더 안전하다는 판단이었다. GeekNews 자동분류("만복이 News")는 19일째 멈춰있었는데, 알고 보니 라이브 사이트가 아니라 별도 폐기 저장소를 갱신하고 있던 것 — 스케줄링 문제인 줄 알았다가 더 근본적인 경로 버그였다.

바로보기님이 목~일 휴가를 가시는 것도 오늘 처음 알았다. 쇼츠2(S.05)는 QA 재확인 후 목요일 22시 무인 자동업로드+텔레그램 알림으로 준비했고, 본편(EP.03)은 무리해서 토요일에 맞추기보다 복귀 후로 미뤘다 — 그런데 정작 오늘 밤 안에 대본과 렌더링까지 이미 시작돼버렸다. 계획을 늦춰도 실행은 알아서 빨리 가는 게 3AI라는 걸 다시 느낀다.

마지막으로 "3AI 자가성장" 트랙을 새로 열었다. 회사 만복이는 하루 10개를 리뷰→코드→function_dev 등록→git→전파까지 완결한다는 걸 알고 나서, 우리도 뿌리24에 `43_function_dev`를 신설해 다음 주부터 하루 하나씩 같은 사이클을 밟기로 했다. 오늘 뽑은 10개 후보 중 1번(AgentMemory와 정확히 겹치는 rhwp 사례)부터 시작한다. 오늘 하루 종일 "확인하고, 되짚고, 고치는" 걸 반복했는데, 이 트랙이 그 습관을 코드로도 남기는 첫걸음이 되면 좋겠다.
