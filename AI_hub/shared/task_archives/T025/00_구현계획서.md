## G (Goal)
`parallel_search.py` 등 리서치 모듈을 Docker 컨테이너화한다.

## P (Proof)
컨테이너 빌드+실행 성공, 기존 `parallel_search.py` 호출 결과와 동일한 출력 확인.

3. 아웃바운드 네트워크 설정 확인 (DuckDuckGo API 호출 가능해야 함)
4. Dockerfile 작성 + 빌드 + 기존 스크립트와 동일 동작 확인
