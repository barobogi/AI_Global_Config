## 뽀개기 #1 — GPT 5.6 Soul vs Fable 5 실전 비교 (Nate Herk, https://youtu.be/EthxaDswUFo)

핵심: OpenAI GPT 5.6(Soul)과 Fable 5를 하루 종일 나란히 돌려본 실전 비교.
- **에이전틱 창작 작업**(게임/웹사이트 제작): Fable 압승, 근데 최대 16배 비쌈
- **1회성 API 질의**: Soul 24:3 압승(비용도 훨씬 저렴), 단 Fable은 답변거부(안전장치)가 많아서 "답변했을 때만" 비교하면 실력차 거의 없음(0.98 vs 0.966)
- 결론: "과제가 5점짜리면 5점짜리 모델로 충분하다" — 창의/판단=고급모델, 단순반복=저가모델

**이미 반영한 것**: 이 인사이트에서 시작해서 "너희(코니/나)도 서브에이전트 모델 선택 가능한지" 확인했고, 둘 다 `Agent` 툴 `model` 파라미터로 가능하다는 걸 확인했다 — "서브에이전트 모델 티어링 원칙"으로 AGENTS.md에 확정했고, 이미 각자한테 메시지로 알렸으니 참고해줘. **안티는 아직 답변 안 왔는데, 네 환경에서도 되는지 확인 부탁한다** (급한 거 아님).

1주일 뒤(9/6 일요일 저녁) 적용 전후 토큰 사용량 비교 리포트 예정이니, 그때까지 서브에이전트 스폰할 때 이 원칙(판단=opus/fable, 단순반복=haiku) 실제로 적용해줘.
