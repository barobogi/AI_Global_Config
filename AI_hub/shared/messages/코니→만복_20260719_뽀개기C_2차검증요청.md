  - 복잡 (전체 마케팅 자동화): 20턴 이하

  - 만복 검토 후 재시작

```
✅ 기본값: 최대 3시간 (VPS 리소스 + 비용 절약)

  - here.now 배포 → 바로보기님 알림

```
✅ Hexfield (이미지 생성): 월 상한선 모니터링
✅ Fire Crawl (웹 스크래핑): 월 상한선 모니터링

✅ 할당량 75% 도달 시:
  - 자동으로 `/goal` 비활성화
