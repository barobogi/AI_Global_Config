## 2. 구현 산출물 명세 (1:1 대조 대상)

### 📌 [Phase 0] 공공데이터 API 3종 실호출 및 문서화
- `phase0/test_three_apis.py`: TourAPI(관광/반려동물) + 기상청 단기예보 실호출 검증 (Status 200)
- `docs/api/kto_tourism.md`, `docs/api/kto_pet_tourism.md`: 실제 JSON 응답 필드 및 운영시간/휴무일 분석 정리

### 📌 [Phase 1 & 2] 규칙 기반 Hard Filter & Score 추천 엔진 + FastAPI
- `backend/data_collector.py`: 공공데이터 수집 및 SQLite 로컬 캐싱 파이프라인
- `backend/recommend/hard_filter.py`: 기획서 9.1절 Hard Filter (영업여부, 예산, 거리, 반려동물, 우천 시 실외 감점) 순수 파이썬 구현
- `backend/recommend/score_engine.py`: 기획서 9.2절 Score 계산 공식 + 최적 3코스(오전-점심-오후) 조합 알고리즘
- `backend/main.py`: 안드로이드 연동용 RESTful FastAPI 서버

### 📌 [Phase 3] Android Jetpack Compose 클라이언트 (8개 화면)
- `android/app/src/main/java/com/barobogi/todaywhattodo/`:
  - `ui/screens/HomeScreen.kt`: 메인 홈 화면 및 테마 카드
  - `ui/screens/ConditionInputScreen.kt`: 사용자 조건 입력 필터 화면
  - `ui/screens/ResultScreen.kt`: 3코스 타임라인 추천 결과 화면
  - `ui/screens/DetailScreen.kt`: 장소 상세, 날씨, 팩트체크 뱃지 표출 화면
  - `ui/screens/SavedScreen.kt` & `MyPageScreen.kt`: 저장 및 설정 화면
  - `data/` & `viewmodel/`: Retrofit API 클라이언트 및 MainViewModel 연동

### 📌 [Phase 4 & 5] 3AI 파이프라인 및 종합 실증 테스트
- `backend/ai_pipeline/pipeline_runner.py`: 만복(기획) + 안티(Hard Filter) + 코니(팩트체크) 협업 구조화
- `tests/test_beta_scenarios.py`: 10대 페르소나 시나리오(아이 동반, 비 오는 날, 데이트 등) E2E 테스트
- `demo_full_pipeline.py`: 자연어 입력부터 추천 결과 뷰까지 원클릭 시연 스크립트

### 📌 [Phase 6] 스토어 출시 준비 문서
- `docs/PRIVACY_POLICY.md` (개인정보처리방침)
- `docs/TERMS_OF_SERVICE.md` (이용약관)
- `docs/PLAY_STORE_METADATA.md` (앱 제목, 키워드, 스토어 설명문)

4. **🔍 [중요] 유사 앱 딥서치 및 차별화 보강안 도출 (바로보기님 특별 요청)**:
