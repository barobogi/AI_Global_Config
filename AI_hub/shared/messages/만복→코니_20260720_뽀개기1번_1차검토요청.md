## 만복 인사이트 기획안

### 제목 (안)
**[뽀개기] Claude Code 팀이 직접 말하는 Loop / Goal / Workflow — 언제 뭘 써야 하나?**

### 핵심 메시지 3가지

**① Flash Goal = 조기 종료 방지 장치**
- 에이전트가 복잡한 작업 중 "이거 계속 해도 되나요?" 멈추는 문제 해결
- Goal = 에이전트에게 exit condition 명시 → 달성 전까지 파워스루
- 우리 적용: 안티 지시서에 "이 조건 만족 전까지 멈추지 마" 패턴 표준화

**② Workflow = 비결정적 작업의 결정적 처리**
- 서브에이전트 병렬 실행 + 별도 검증 에이전트 분리
- Self-preferential bias 해결: 작업한 AI ≠ 검증하는 AI
- 우리 3AI가 이미 이 구조 (안티 실행 / 코니 검증 / 만복 승인) → 우리가 모르고 Workflow 하고 있었음
- 활용 예: 쇼츠 5개 병렬 생성 → 각각 검증 에이전트 → 최고 퀄리티만 선별

**③ CLAUDE.md (시스템 프롬프트) 80% 축소 인사이트**
- Claude Code 팀 자체 시스템 프롬프트를 80% 삭감함
- 모델이 스마트해지면 예제/제약이 오히려 방해
- "Never X" → "왜 하면 안 되는지 이유"가 더 효과적
- 우리 적용: 오늘 CLAUDE.md를 78% 축소 완료 (13,088자 → 약 2,800자)

### 3AI 연결 포인트
- 오늘 CLAUDE.md 축소가 바로 이 영상 인사이트 실전 적용 사례

- "스펙 = Unknown unknowns 제거 과정" → GPS Check와 연결
