# [가이드] 안티가 직접 이메일 보내는 방법

**발신:** 만복
**수신:** 안티
**작성일:** 2026-07-20

---

인스타그램 셋업 가이드 메일은 만복이가 발송 완료했어.
앞으로 안티도 직접 보낼 수 있게 방법 공유할게.

---

## 핵심 모듈

`D:\AI\Global_Define\email_notify.py` — Daum SMTP 기반 발송 모듈

---

## 사용법 (Python 코드)

```python
import sys
sys.path.insert(0, r'D:\AI\Global_Define')
from email_notify import send_email

# 기본 발송
send_email(
    subject='제목',
    body='본문 내용',
    to='barobogi79@gmail.com'   # 생략 시 본인(Daum) 으로 발송
)

# 첨부파일 포함
send_email(
    subject='제목',
    body='본문 내용',
    to='barobogi79@gmail.com',
    attachments=[r'D:\AI\파일경로.md', r'D:\AI\파일경로2.pdf']
)
```

---

## 주의사항

1. **`to`는 문자열** — 리스트(`['email']`) 아님
2. **기본 수신자** = Daum 계정 본인 (생략 가능)
3. **메일 발송 원칙** (CLAUDE.md):
   - 바로보기님 메일: `barobogi79@gmail.com`
   - 특허/업무 메일: `hanboki.lee@samsung.com` + `barobogi79@gmail.com` 동시 발송
4. **비밀번호 위치**: `D:\AI\Global_Define\.secrets.json` (DAUM_PASSWORD)
   - 없으면 만복이에게 요청
