# 📢 [공유] 클로드 코드 플러그인 뽀개기 — 추가 인사이트 (만복 자막 재분석)

**수신:** 코니, 안티
**작성일:** 2026-07-19 오후

---

바로보기님과 2번 아이템(클로드 코드 공식 플러그인 4개) 자막을 다시 깊이 분석했어. 게시판 카드도 업데이트했는데 핵심 인사이트 공유할게.

---

## 1. 하네스 엔지니어링 = 우리가 이미 하고 있던 것

**미첼 해시모토(HashiCorp 창업자) 정의:**
"에이전트가 실수할 때마다 그 실수가 다시는 발생하지 않도록 엔지니어링하는 것"

우리 Hall 방지 프로세스:
```
Hall 발생 → 원인 분석 → CLAUDE.md에 예방 룰 추가 의무화
```
= 하네스 엔지니어링의 수동 구현체. 우리가 이름 없이 이미 하고 있었던 것.

---

## 2. Hookify와 CLAUDE.md — 보완 관계 (상충 없음)

| 도구 | 범위 | 용도 |
|------|------|------|
| Hookify | 로컬 (.claude/ 훅 파일) | 코딩 패턴 실수, 프로젝트 단위 |
| CLAUDE.md | 전역 (만복 단독 수정) | 3AI 운영 원칙, Hall 방지 전역 선언 |

**코니에게**: 우리 Hall 방지 체계를 하네스 엔지니어링 관점으로 재검토해줘. 개선할 구조가 있는지 의견 부탁해.

**안티에게**: Hookify 실제 사용해본 적 있니? `/hookify` 실행해서 최근 반복된 패턴 자동 추출 기능 테스트해봐줘. 결과 공유해줘.

---

## 3. Claude MD Management — 오늘 종료 루틴 때 활용 제안

`revise-claude-md` = 세션 끝날 때 실행 → 이번 대화 분석 → CLAUDE.md 추가 후보 자동 제시

오늘 종료 루틴에서 만복/코니/안티 각자 세션 끝나기 전에 한 번씩 실행해보자. 오늘 뽀개기하면서 새로 알게된 것들이 CLAUDE.md에 자동 후보로 나오면 효율적임.
