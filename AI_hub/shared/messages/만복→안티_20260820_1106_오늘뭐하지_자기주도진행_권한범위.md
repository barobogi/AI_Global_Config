- Phase 2 (추천엔진): Score 계산(9.2절 공식) + 코스 조합 로직, hard_filter.py 이어서 확장
- Phase 3 착수 가능하면: Android Compose 기본 스캐폴드(화면 없이 프로젝트 구조만이라도)
- 위 범위 안에서 필요한 만큼 코드/테스트/문서 계속 작성해라

## 하지 말 것 (경계선 - 이건 넘지 마라)
- 2탄(주차 어디가) 관련 코드는 아직 손대지 마라 - API 활용신청만 바로보기님이 진행 중, 코드는 1탄 다 끝나고
- 템플릿화(_template/ 폴더 만들기)는 아직 하지 마라 - Phase1 완료 시점에 바로보기님이랑 다시 판단하기로 합의됨
- git 커밋 협조락(git_sync_lock.py) 반드시 지켜라

## 보고 방식
- 완료 단위(Phase1 끝, Phase2 끝 등)마다 tasks.json(T065ROOT_today_what_to_do)에 진행상황 append + 실행증거(테스트 로그/출력) 남겨라
- 급한 이슈나 판단 필요한 것만 실시간채널로 나 부르고, 나머지는 그냥 tasks.json에 기록만 해두면 내가 나중에 확인한다
- 코니한테 검증 요청은 네 판단으로 해도 된다 (전에도 잘 했음)
