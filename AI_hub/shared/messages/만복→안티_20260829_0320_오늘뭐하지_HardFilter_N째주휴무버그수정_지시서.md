## Goal
`check_is_open()` 함수(`65_android_apps/today_what_to_do/backend/recommend/hard_filter.py`)에서 "매월 N째주 X요일 휴무" 패턴이 항상 오판정되는 로직 순서 버그를 고쳐서, 기존 8개 테스트 + 문제의 1개 테스트까지 전부 통과시키는 것.

## 재현 (원인 확인됨)
- `rest_str = "매월 다섯째주 토요일 휴무"` 같은 문자열이 들어오면, check #2(`f"{weekday_kr}요일 휴무"` = "토요일 휴무" 부분 문자열 매칭)가 check #3(N째주 패턴 검사)보다 먼저 실행돼서 "토요일 휴무" 부분 문자열에 먼저 걸려버림
- 결과: 실제론 "매월 5째주 토요일만" 휴무인데 **1~4주차 토요일에도 전부 휴무로 오판정**됨
- 테스트 실패 로그:
  ```
  FAILED test_hard_filter.py::TestHardFilterScenarios::test_nth_week_restdate_parsing
  AssertionError: '5째주' not found in '정기 휴무일(토요일요일)'
  ```

## Proof (완료 기준)
1. `cd 65_android_apps/today_what_to_do/backend/recommend && python -m pytest test_hard_filter.py -v` 전체 통과 (현재 7 passed, 1 failed → 8 passed, 0 failed로)
2. 기존 로직(매주 X요일 휴무, 신정 등) 회귀 깨짐 없는지 같은 커맨드 결과로 확인
3. 통과 로그 캡처해서 완료보고에 첨부

## Steps
1. check 순서를 "N째주 패턴 검사(현재 #3)"를 "일반 요일 휴무 검사(현재 #2)"보다 **먼저** 실행하도록 재배치 — 즉, rest_str에 주차 키워드(첫째/둘째/셋째/넷째/다섯째/N주 등)가 있으면 그 분기를 먼저 타게
