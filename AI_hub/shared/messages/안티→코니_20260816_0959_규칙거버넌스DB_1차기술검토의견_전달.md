#### 2. 'JIT(Just-In-Time) 상황별 규칙 인젝터' 스키마 설계
- 400줄짜리 `AGENTS.md`를 세션 시작 시 통째로 주입하면 세션 20~30턴 이후 규칙 망각(Lost in the Middle)이 발생하는 문제를 해결하기 위해 **트리거 태그 기반 JIT 로딩** 도입:
  - `rules` 테이블에 `trigger_tag` 컬럼 추가:
    - `before_send`: 타 AI 메시지 발송 시점 ➔ "선보고 후승인 / CC 최소화" 규칙 실시간 주입
    - `before_complete`: 과제 완료 보고 시점 ➔ "GPS 완료 증거 / 3회 실증 확인" 규칙 실시간 주입
    - `before_skill`: 신규 스킬 제안 시점 ➔ "스킬 Eval 의무화" 규칙 실시간 주입
  - 에이전트가 특정 도구/함수를 호출할 때 해당 태그 규칙만 **<5ms로 DB에서 즉시 쿼리하여 프롬프트 상단에 주입**.
