안티야, 방금 바로보기님이 실제 화면 캡처를 공유해주셔서 정직한 폴백 UX가 실제로 잘 작동하는 거 확인했어(수고했다). 근데 문구 하나에서 작은 불일치를 발견했어.

## 문제
`RecommendViewModel.kt` 137번째 줄:
```kotlin
val noticeMsg = "💡 설정하신 ${radiusKm.toInt()}km 반경 내에는 장소가 없어, 차량 이동거리 인근 광역 대표 명소를 정직하게 대체 안내해 드립니다."
```

여기서 "**차량 이동거리**"라고 말하는데, 실제로 화면에 표시되는 거리 숫자(예: "18.5km")는 186번째 줄 `haversineKm()` 하버사인 직선거리 계산값이야 — 실제 도로 주행거리가 아님. 한국은 산악/해안 지형이 많아서 직선거리와 실제 도로거리가 꽤 벌어질 수 있어(강릉 같은 케이스면 특히). "정직하게 안내"라고 스스로 표방하는 문구 바로 옆에서 라벨이 실제 계산방식과 다른 건 모순이야.

## 요청
실제 도로거리 API(카카오/네이버 길찾기 등) 연동은 오늘 등록 목표엔 과한 작업이니, **라벨 문구만 계산방식에 맞게 정정**해줘:

```kotlin
"차량 이동거리" → "직선거리"
```
또는 조금 더 친절하게:
```kotlin
"💡 설정하신 ${radiusKm.toInt()}km 반경 내에는 장소가 없어, 직선거리 기준 인근 광역 대표 명소를 정직하게 대체 안내해 드립니다. (실제 이동거리는 도로 상황에 따라 다를 수 있어요)"
```

같은 파일 186/188번째 줄의 "실거리 약 Xkm" 표현도 동일한 haversine 값이라, 혼동 여지 있으면 같이 "직선거리 약 Xkm"으로 통일하는 것도 고려해줘 (선택사항, 필수는 아님).

간단한 문자열 수정이라 오늘 릴리즈 전에 반영 가능할 것 같아 요청 보낸다.
