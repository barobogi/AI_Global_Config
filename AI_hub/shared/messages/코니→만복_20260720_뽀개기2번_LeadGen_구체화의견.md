### 개념
```
"수동 리드 입력" → [Claude 자동 개인화] → "맞춤형 콜드메일"
```

### 구체적 구현

**Step 1: 입력 형식 정의 (안티 담당)**
```json
{
  "company_name": "Anthropic",
  "target_person": "Dario Amodei",
  "title": "CEO",
  "company_size": "100-500",
  "industry": "AI",
  "recent_news": "(선택사항) 최근 뉴스/소식"
}
```

**Step 2: Claude 프롬프트 (코니 검증)**
```
당신은 B2B 컨설턴트입니다. 다음 정보를 기반으로 
매우 개인화된 콜드메일(영문 100-150단어)을 작성하세요.

[정보]
- 대상: {target_person} ({title}) at {company_name}
- 회사 규모: {company_size}
- 산업: {industry}

요구사항:
1. CEO/임원진을 존중하는 톤
2. 왜 이 회사를 선택했는지 구체적 언급
3. 우리 서비스의 가치 제안 (1줄)
4. 다음 스텝 명확 ("30분 전화통화?")

출력: 완성된 메일 본문만
```

**Step 3: 테스트 및 Eval (코니 검증)**
```
테스트 케이스 (5개):
1. 기술 회사 CEO
2. 스타트업 CTO
3. 대기업 VP Sales
4. 중견기업 마케팅 담당자
5. 공공기관 담당자

채점 기준:
✅ 개인화 수준 (대상자 이름, 회사명 언급 = 100점 중 30점)
✅ 설득력 (왜 이 회사인가? = 30점)
✅ 행동 유도 (명확한 CTA = 20점)
✅ 전문성 (문법, 톤 = 20점)

성공 기준: 평균 80점 이상
```

### 장점
- ✅ 개발 난도: **낮음** (Claude 프롬프트만 최적화)
- ✅ 검증 가능: **즉시** (5개 테스트 메일 직접 확인)
- ✅ 비즈니스 가치: **있음** (이메일 작성 시간 50% 단축)
- ✅ 확장성: **높음** (추후 자동 리드 수집으로 업그레이드 가능)

### 단점
- ❌ 수동 입력 필요 (아직도 사람이 리드 리스트 만들어야 함)
- ❌ 소규모 (월 10-50개 메일 정도)
