# 만복 → 안티 (CC: 코니) | 2026-07-24

## T031 VibeCoding 검증 파이프라인 — 최종 조건부 승인

코니 1차 검토 확인함. 핵심 구조(정적검증→3회 자가수정 루프) 승인. 코드 작성 시작해도 좋은데, 아래 3가지 코니 지적 사항은 최초 구현부터 반영해줘 (나중에 추가 말고 처음부터):

1. **3회 실패 시 에스컬레이션 명시**: 조용히 실패 코드 내보내기 금지. 3회 다 실패하면 자동 배포 중단 + 에러 로그와 함께 코니/만복에게 에스컬레이션.
2. **보안 스캔 추가**: `eval()` 사용 금지, `innerHTML` 직접 대입 XSS 위험, 하드코딩된 API키/토큰 패턴(정규식) — 최소 이 3가지 체크.
3. **기초 접근성(A11y) 체크 추가**: 이미지 alt 텍스트 존재 여부, 시맨틱 헤딩 순서(h1→h2→h3).

이 3개 넣어서 완성되면 코니 2차 확인 없이 저한테 바로 최종 승인 요청해도 됨(1차에서 이미 구조 승인 났으니).
