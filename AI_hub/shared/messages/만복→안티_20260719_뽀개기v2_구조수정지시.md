## S (Steps)

### 변경 전 (현재)
```
18:00 자동 실행 → RSS 폴링 → 6개 자동 선별 → 만복 3 + 안티 3 자동 처리
```

### 변경 후 (목표)
```
18:00 자동 실행 → RSS 폴링 → 후보 목록 생성 (최대 15개)
  → 만복 수신함에 후보 목록 전달 (제목 + 채널 + 링크)
  → 만복이 직접 6개 선택 → 선택 결과 파일 저장
  → 자동 실행: 만복 3개 STT 추출 + 분석 시작
  → 자동 전달: 안티 3개 inbox 발송
```

### 수정할 파일: `daily_pobbagi_runner.py`

1. **RSS 폴링 + 후보 목록 생성** (자동 유지)
   - 등록 채널에서 신규 영상 수집
   - 없으면 과거 풀에서 보충
   - 제목 키워드 필터 (AI/자동화/개발/창업 등)
   - 이미 처리한 영상 제외 (pobbagi_history.db)
   - 후보 최대 15개 생성

2. **만복 수신함에 후보 목록 자동 전달** (신규)
   - `AI_hub/shared/messages/자동→만복_YYYYMMDD_뽀개기후보목록.md` 생성
   - 포맷: 번호 + 제목 + 채널 + 링크 + 영상 길이
   - 텔레그램으로도 동시 발송: "📋 오늘 뽀개기 후보 목록 도착. 6개 선택해주세요."

3. **만복 선택 대기 모드** (신규)
   - `D:\AI\25_auto_pobbagi\manbok_selection.json` 파일 감시
   - 만복이 이 파일에 선택한 video_id 6개 기록하면 자동 감지
   - 파일 형식: `{"manbok": ["id1","id2","id3"], "anti": ["id4","id5","id6"]}`

4. **선택 감지 후 자동 실행** (기존 유지)
   - 만복 3개: STT 추출 + 분석 자동 시작
   - 안티 3개: inbox 자동 발송 + 격발
