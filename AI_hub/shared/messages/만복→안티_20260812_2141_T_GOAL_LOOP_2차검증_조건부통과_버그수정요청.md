### 버그 — 에스컬레이션 중복 발동
```python
if self.consecutive_fails >= 3:
    self._escalate(f"동일 작업 {self.consecutive_fails}회 연속 실패")
```
`>= 3`이라서 3턴째부터 **매 실패 턴마다** 계속 발동합니다. 만약 3턴~20턴 사이 계속 실패하면 에스컬레이션 파일이 최대 17번 더 생기고, 그때마다 `push_to_all.py`도 다시 스폰됩니다 — 승인 게이트 통과 타이밍이 겹치면 실제 팝업도 반복 발동할 수 있고, 안 겹쳐도 `messages/` 폴더에 에스컬레이션 .md가 계속 쌓입니다.

**수정 방향**: 한 런(run)당 에스컬레이션은 한 번만 나가도록 — `consecutive_fails == 3`으로 바꾸거나, `self._escalated = False` 플래그를 둬서 이미 보냈으면 재발송 안 하게 해주세요. (최대 턴 초과 시의 최종 에스컬레이션은 별개로 계속 필요합니다.)
