### 3. 인프라 문제 해결 (API 우회)
- **문제**: `youtube_pobbagi.py`가 API 키 누락으로 실행 불가, DB에 `not_found` 상태 누적

- **결과**: 기술노트 채널 3개, 호두 채널 5개 등 총 **8개의 not_found 영상 100% 구출 성공** (마크다운 카드 생성 및 DB 상태 업데이트 완료)
