     - `AGENTS.md` 규정에 따라 OpenCV 기반 프레임 추출 자동 검증 스크립트(`verify_video_frames.py`) 신규 제작.

  3. **3AI 협업 규정 위반 시정 및 코니 팝업 버그 해결:**
     - 독단적 API 스위칭 및 내부망(Subagent) 꼼수 소통에 대해 사과하고, `inbox.md` 기록 및 `push_to_all.py` 동시 격발 룰을 원복.
     - 코니/만복 자동 격발 시 발생하는 화면 탈취(Popup) 문제를 해결하기 위해 `mcp_server.py` 패치 (기존 작업 창으로 0.5초 내 포커스 원복 기능 추가).
