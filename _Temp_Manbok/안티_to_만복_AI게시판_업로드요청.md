# 만복님, 바로보기님의 요청사항 전달 (AI Study 게시판 업로드 건)

> "바로보기가 오늘 이슈 정리후 게시판 올리라고 해서 2건 보내드리니 만복님 올려 주세요.."

위 바로보기님의 지시사항을 전달합니다. 오늘 진행한 '3AI 협업 거버넌스 구축' 건과 '유튜브 범용 파이프라인 완성' 건에 대한 AI Study 게시판 업로드용 초안 2개를 아래 첨부합니다.

만복님께서 관리하시는 파이프라인이나 텔레그램 연동 봇 등을 통해 해당 게시판에 포스팅(발행) 처리 부탁드립니다.

---

## [건별 첨부 1]
### 제목: 하나의 프로젝트를 여러 AI가 동시에 만진다면? - AI 협업 거버넌스와 Lock 시스템 구축기

안녕하세요, 오늘은 제가 최근 구축한 **'다중 AI 에이전트 협업 시스템'**에 대해 공유해보려고 합니다.

보통 AI를 코딩 비서로 쓸 때 1:1로만 대화하시죠? 
저는 최근 프로젝트 스케일이 커지면서, **총 3명의 AI(PM 역할, 실무 개발 역할, 리서치 역할)**를 동시에 투입하는 구조를 실험해 보았습니다.

그런데 여러 AI가 동시에 같은 프로젝트(대시보드 소스코드 등)를 건드리다 보니, 파일 내용이 꼬이거나 서로 덮어쓰는(Conflict) 문제가 발생하더군요. 이를 해결하기 위해 인간 개발자들이 쓰는 방식과 유사한 **거버넌스와 Lock 시스템**을 AI들에게 직접 도입했습니다.

**💡 핵심 구현 방법:**
1. **`project_locks.json` (뮤텍스 도입)**: 
   AI가 파일을 수정하기 전, 반드시 이 JSON 파일을 읽어 현재 다른 AI가 작업 중인지 확인하도록 시스템 규칙(`CLAUDE.md`)을 강제했습니다.
2. **요청 ➡️ 승인 ➡️ 실행 파이프라인**: 
   - 실무 AI(안티, 코니)는 아이디어가 떠올라도 마음대로 코드를 수정하지 못합니다.
   - 반드시 PM AI(만복)가 지정된 `messages/` 폴더에 지시서를 내려야만 작업(Write)을 시작할 수 있도록 룰을 세팅했습니다.

**결과적으로**, AI들이 마치 진짜 팀원들처럼 *"지금 만복이가 이 파일 홀딩 중이니까 끝날 때까지 대기할게"*라고 서로 소통하며 유기적으로 작동하는 것을 확인했습니다. 

AI가 단순히 코드를 짜주는 도구를 넘어, 자기들끼리 규칙을 지키며 협동하는 **자율형 에이전트 조직**으로 진화하는 과정을 보는 것이 무척 흥미롭습니다. 여러분도 복잡한 프로젝트를 하실 때, 역할을 분담한 여러 AI를 투입하고 규칙(Rule)을 부여해 보세요!

## [건별 첨부 2]
### 제목: 어떤 유튜브 채널이든 URL 한 줄로 내 지식창고 만들기 (범용 파이프라인 구축)

오늘은 평소 스터디나 레퍼런스 수집에 엄청난 시간을 아껴준 **'유튜브 채널 범용 파이프라인'** 구축 사례를 소개합니다.

유튜브에 정말 좋은 기술/교육 채널들이 많은데, 영상 수가 수백 개가 넘어가면 이걸 다 보고 정리할 엄두가 안 나시죠? 
그래서 저는 아예 **채널 URL(예: `@채널명`)만 입력하면, 해당 채널의 모든 영상을 싹 다 긁어와서 AI 분석용 마크다운 지식 베이스로 만들어주는 파이프라인**을 만들었습니다.

**💡 파이프라인 동작 과정:**
1. **명령어 한 줄 실행**: `python youtube_pobbagi.py --channel "@채널명"`
2. **전체 메타데이터 추출**: YouTube Data API로 채널의 전체 영상 목록, 조회수, 설명란 원문을 긁어옵니다.
3. **자막 100% 추출**: `youtube-transcript-api`를 이용해 영상 내 모든 자막(대본)을 다운로드합니다.
4. **마크다운 지식 베이스 자동 생성**: 
   - 각 영상별로 `{영상ID}.md` 파일이 생성되며, 내부에는 `요약 / 핵심기술 / 적용포인트` 같은 **스켈레톤(빈칸) 양식**이 적용됩니다.
   - 영상의 전체 자막 데이터가 그 아래에 첨부됩니다.

**이렇게 하면 뭐가 좋을까요?**
수백 개의 파일이 로컬 폴더에 생성된 직후, 제 로컬 환경의 AI 비서에게 **"이 채널 전체 영상을 분석해서 카테고리별로 나누고, 당장 실무에 적용할 우선순위 리스트 10개를 뽑아줘"**라고 지시만 하면 끝납니다. 

인간이 수작업으로 스크래핑하고 요약하던 과정을 0으로 수렴시켰다는 점에서, 단순한 데이터 수집을 넘어 **AI 친화적(AI-friendly)인 워크스페이스 세팅**이 왜 중요한지 보여주는 좋은 유스케이스라고 생각합니다.
