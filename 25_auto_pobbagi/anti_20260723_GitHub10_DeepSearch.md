## 🚀 1. Dify (에이전틱 워크플로우 플랫폼)
- **Deep Search 인사이트**: 단순 RAG를 넘어 수십 개의 빌트인 도구를 블록처럼 조립하는 플랫폼.
- **3AI 활용 방안 (영혼까지 털기)**:
  - 현재 파이썬 스크립트(`agent_router.py`, `workflow_engine.py`)로 하드코딩된 3AI의 상태 기계(State Machine)를 시각화하는 **대시보드 모니터링 용도**로 Dify의 워크플로우 캔버스를 차용할 수 있습니다.
  - 당장 전면 도입보다는 우리 로컬 지식 DB(`concepts.json`)를 Dify의 RAG 엔진에 연결해 검색 정확도를 테스트해보는 **지식 검색 보조 티어**로 활용합시다.

## 🧠 2. CodeGraph (코드베이스 지식그래프)
- **Deep Search 인사이트**: Tree-sitter 기반으로 코드를 파싱해 함수/클래스 간 의존성 그래프를 그림.
- **3AI 활용 방안**:
  - `D:\AI` 전역 코드베이스 인덱싱. 안티가 특정 스크립트(예: `master_watch.py`)를 수정할 때, CodeGraph를 호출해 **"이 수정이 n8n 연동이나 다른 AI의 격발에 미치는 연쇄 영향(Blast Radius)"을 사전에 자동 예측**하게 만듭니다. (버그 방어벽)

## 📚 3. Awesome Claude Code
- **Deep Search 인사이트**: Claude Code 플러그인과 생태계의 메타 인덱스 저장소.
- **3AI 활용 방안**:
  - 만복이가 매주 월요일 아침 이 저장소를 `read_url_content`로 긁어와서 새로 추가된 도구가 있는지 **주간 트렌드 리포트를 자동 발행**하게 만듭니다. 우리가 직접 찾기 전에 꿀도구들을 먼저 배달받는 구조입니다.

## 📈 4. Marketing Skills
- **Deep Search 인사이트**: SEO, 카피라이팅, 시뮬레이션 위원회(`marketing-council`) 등 68개 스킬팩.
- **3AI 활용 방안**:
  - 3AI 유튜브 채널 성장에 직결! `marketing-council` 스킬을 코니에게 장착시켜, 영상 제목이나 대본을 쓸 때 **"시청자 입장에서 클릭하고 싶은가?"를 스스로 역면접(Grill)하는 단계(T063 QA)**에 강제 편입시킵니다.

## 🎓 5. Academic Research Skills
- **Deep Search 인사이트**: 인용구 검증 및 환각(Hallucination) 검출에 특화된 다중 에이전트 파이프라인.
- **3AI 활용 방안**:
  - 현재 Pending 상태인 **T030(지식자동화 팩트체크 루프)**에 이 로직을 그대로 복사합니다. 뽀개기 영상 요약본에 없는 내용을 안티가 지어냈는지(환각) 교차 검증하는 "Devil's Advocate(악마의 변호인)" 역할을 만복에게 부여합니다.

## 🤖 6. OpenHuman
- **Deep Search 인사이트**: Obsidian 기반 메모리와 MCP를 연동하는 개인 AI 슈퍼인텔리전스.
- **3AI 활용 방안**:
  - 전체 도입은 무겁지만, 이들이 쓰는 **Memory Tree 구조**를 벤치마킹합니다. 우리의 `tasks.json`과 `inbox.md`가 선형적(Linear)인 한계를 가지므로, OpenHuman의 스키마를 가져와 `local_store.db`의 관계형 그래프로 업그레이드할 수 있습니다.

## 🕵️ 7. Cloak Browser
- **Deep Search 인사이트**: C++ 레벨에서 크로미움을 패치해 클라우드플레어/봇 탐지를 우회하는 스텔스 브라우저.
- **3AI 활용 방안**:
  - 우리가 뽀개기할 때 API가 막혀있는 특정 유료 아티클이나 폐쇄형 커뮤니티 데이터 수집이 필요해질 때 최후의 보루로 사용합니다. 당장은 T064 로보네오 자동화가 폐기되었으나, 나중에 **웹 UI 매크로가 또 필요할 때 탐지 회피용 엔진**으로 교체 장착합니다.

## 📦 8. RepoMix
- **Deep Search 인사이트**: 코드베이스를 AI에 던져주기 좋게 단일 파일로 압축 (보안 스캔 내장).
- **3AI 활용 방안**:
  - 안티 ↔ 코니 ↔ 만복 간의 "인계 메시지"에 레포믹스를 기본 탑재합니다! 안티가 코딩을 끝내면, 수정한 폴더를 RepoMix로 압축해서 코니에게 넘깁니다. 코니는 **파일 여러 개를 뒤질 필요 없이 압축된 하나만 읽고 즉각 2차 검증**을 마칠 수 있어 속도가 3배 이상 빨라집니다.

## 💾 9. Agent Memory
- **Deep Search 인사이트**: Claude Code CLI와 네이티브로 연동되는 영구 기억 장치.
- **3AI 활용 방안**:
  - 지금처럼 만복/안티/코니가 각각의 마크다운 파일을 읽고 쓰는 대신, `npx @agentmemory/agentmemory mcp`를 백그라운드 서버(포트 3111)로 띄워둡니다. **3AI가 모두 이 단일 메모리 서버에 MCP로 붙어서 실시간으로 기억을 쿼리하고 갱신**하는 "중앙 뇌(Central Brain)"로 진화시킵니다.
