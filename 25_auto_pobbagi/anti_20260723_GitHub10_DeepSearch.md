## 🚀 1. Dify (에이전틱 워크플로우 플랫폼)
- **저장소**: `langgenius/dify` (149k+ 스타)
- **기술 스펙**: LLMOps, 시각적 RAG 파이프라인, 50+ 빌트인 툴, Apache 2.0.
- **3AI 활용 방안 (영혼까지 털기)**:
  - **시각적 대시보드 차용**: 현재 `tasks.json`과 `inbox.md` 기반으로 돌아가는 3AI의 라우팅 흐름(`agent_router.py`)은 백그라운드에 숨어 있어 바로보기님이 직관적으로 보기 어렵습니다. Dify의 워크플로우 캔버스(프론트엔드)만 벤치마킹하여, 현재 **만복/코니/안티 중 누가 어떤 태스크를 쥐고 있는지 실시간으로 보여주는 웹 대시보드**를 만듭니다. (FastAPI + React로 자체 구현 가능)
  - **문서(개념노트) 파이프라인 분리**: Dify의 RAG 모듈만 도커로 별도 띄운 뒤, `local_store.db`의 방대한 개념 카드들을 Dify 쪽에 인덱싱합니다. 이후 코니가 리서치할 때 `dify-api`를 호출하면, 직접 로컬 DB를 뒤지는 것보다 훨씬 똑똑하게 연관 개념을 가져올 수 있습니다.

## 🧠 2. CodeGraph (코드베이스 지식그래프)
- **저장소**: `codegraph-ai/CodeGraph` (Tree-sitter 기반)
- **기술 스펙**: AST(추상 구문 트리) 기반 로컬 우선 파싱, 임베딩 불필요(--graph-only 모드).
- **3AI 활용 방안**:
  - **의존성 연쇄 파괴(Blast Radius) 자동 방어**: 안티(저)가 코드를 짤 때 가장 큰 리스크는 기존에 잘 도는 파이프라인(예: `master_watch.py`나 `n8n` 연동)을 건드려서 뻗게 만드는 것입니다. 
  - CodeGraph를 도입해 CI/CD 파이프라인(T022 등)에 물립니다. 제가 코드를 수정하고 커밋하려 할 때, `codegraph map ./` 명령이 백그라운드에서 돌아 **"이 함수를 바꾸면 5개의 다른 파일에 에러가 날 수 있다"고 저에게 스스로 경고(자가 치유 루프)**하게 만듭니다.
