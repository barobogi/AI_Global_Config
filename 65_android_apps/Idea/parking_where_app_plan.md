# 1. 2탄 제품 한 줄 정의

## “지금 내 목적지에 갈 때, 어디에 주차하는 게 가장 좋은지를 대신 결정해주는 앱.”

기존 주차 앱:

> 주변 주차장을 보여준다.

「주차 어디가?」:

> **내 상황을 계산해서 가장 좋은 주차장을 골라준다.**

사용자는 목적지만 입력해도 된다.

앱은 다음 정보를 종합한다.

- 현재 위치
- 목적지
- 현재 주차 가능 상태
- 거리
- 주차요금
- 운영시간
- 무료/유료
- 목적지까지 도보거리
- 예상 이동시간
- 사용자 선호
- 시간대

그리고

> “지금은 A 주차장을 추천합니다.”

라고 답한다.

---

# 2. 핵심 문제

주차 자체보다 어려운 것은 **주차 의사결정**이다.

사용자가 실제로 궁금한 질문:

> “여기 근처 주차장이 어디지?”

보다

> “10분 늦더라도 싼 곳이 좋을까?”
>
> “조금 비싸더라도 바로 앞에 대는 게 좋을까?”
>
> “지금 빈자리가 있을 가능성이 높은 곳은 어디지?”
>
> “주차하고 목적지까지 몇 분 걸리지?”
>
> “오늘 3시간 세워두면 어디가 제일 싸지?”

이다.

따라서 앱의 핵심 가치는 **검색 → 비교 → 선택의 과정을 자동화하는 것**이다.

# 3. 핵심 사용자

## Persona A — 약속이 있는 운전자

예:

> “강남역 7시 약속. 6시 40분 도착 예정.”

필요:

- 가까움
- 빠른 입차 가능성
- 도보거리

## Persona B — 장시간 주차 사용자

예:

> “오늘 4시간 주차해야 함.”

필요:

- 총 주차비
- 최대요금
- 할인 가능성

## Persona C — 가족 외출

필요:

- 주차 후 목적지 접근성
- 대형 주차공간
- 화장실/엘리베이터 등 부가 정보
- 주말 혼잡 가능성

## Persona D — 절약형 사용자

> “조금 걸어도 싸면 됨.”

필요:

- 시간당 요금
- 무료 주차
- 최대 요금
- 할인

# 10. 공공데이터포털에서 사용하는 핵심 데이터

## 10.1 한국교통안전공단_주차정보 제공 API

공식 페이지:

https://www.data.go.kr/data/15099883/openapi.do

공공데이터포털에 따르면:

- 제공기관: 한국교통안전공단
- API 유형: REST
- 포맷: JSON + XML
- 비용: 무료
- 개발계정 트래픽: 10,000
- 운영계정: 활용사례 등록 시 신청하여 확대 가능
- 업데이트 주기: 실시간
- 이용허락범위: 제한 없음
- 심의: 개발/운영 단계 심의승인

또한 시설정보, 운영정보, 실시간 주차정보를 제공한다고 안내되어 있다.

### 서비스 URL

```text
http://apis.data.go.kr/B553881/Parking
```

### 대표 요청주소

```text
http://apis.data.go.kr/B553881/Parking/PrkSttusInfo
```

공식 상세 페이지:
https://www.data.go.kr/data/15099883/openapi.do

공식 페이지에는 `serviceKey`, `pageNo`, `numOfRows`, `format` 등의 요청변수가 안내되어 있으며, 주차장 관리 ID, 주차장명, 주소, 위도·경도, 총 주차구획 수 등의 응답 필드가 제공된다.

# 21. 추천 엔진

```python
if not is_open:
    reject()

    reject()
```

## Score

초기:

```python
score = (
    availability_score * 0.30
    + distance_score * 0.25
    + price_score * 0.25
    + operation_score * 0.10
    + reliability_score * 0.10
)
```

## AI-2

```text
너는 주차 추천 설명 AI다.

절대로 입력 데이터에 없는 가격,

```

## AI-3

```text
너는 주차 추천 Fact Checker다.

- 주차장명
- 가격
- 운영 여부
- 잔여면수
- 혼잡도
- 위치
- 거리
- 업데이트 시각

불일치가 있으면 verified=false를 반환한다.
```

# 33. 상용화에서 중요한 원칙

## “실시간”이라는 단어를 함부로 쓰지 않는다.

공식 API가 실시간으로 제공되더라도:


일 수 있다.

> “공공데이터 기준 마지막 확인: 18:32”

처럼 마지막 업데이트 시간을 표시하는 것이 좋다.
