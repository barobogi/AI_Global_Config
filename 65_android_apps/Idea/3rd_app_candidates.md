## TOP 3 추천 (순위순)

### 1순위 — "지금 갈 수 있는 병원/약국"
- **컨셉**: 증상/시간/위치 입력 → 지금 열려있고 해당 진료과목 있는 병원·약국을 거리순+신뢰도로 추천
- **핵심 API**: HIRA 의료기관별상세정보서비스(시설/진료과목/운영시간), 약국정보서비스
- **왜 좋은 후보인가**: 1탄/2탄과 도메인 완전히 다름, "지금 당장 필요한 의사결정"이라는 점에서 1탄과 톤은 같지만 상황(아플 때)이 훨씬 급박해 리텐션 가치 높음. 순수 규칙기반(운영시간+거리+진료과목 매칭)으로 AI 없이도 핵심 가치 성립 — 1탄/2탄 설계 원칙과 정확히 부합.
- **리스크**: 응급실 실시간 병상현황까지 넣으려면 별도 API(중앙응급의료센터) 확인 필요 — 이번 조사에서 확정 못 함, 없어도 "운영시간+진료과목" 기본 기능만으로 MVP 가능.

### 2순위 — "오늘 뭐 볼까" (문화행사/공연/전시 추천)
- **컨셉**: 위치+기간+장르 선호 입력 → 지금 볼 수 있는 공연/전시/행사 추천
- **핵심 API**: 한국문화정보원 한눈에보는문화정보조회서비스, 문화체육관광부 문화예술공연(통합)
- **왜 좋은 후보인가**: 데이터 품질/구조 좋음(기간·지역·분야·가격·좌표·이미지까지 제공), 규칙기반 적합.
- **리스크**: 1탄("오늘뭐하지")과 컨셉이 근접함(둘 다 "오늘 뭐 하지" 계열 상황 추천) — 차별화(장소 중심 vs 이벤트/티켓 중심) 명확히 하지 않으면 시리즈 내 자기잠식 우려. 3탄보다는 1탄의 확장 기능(추천 카테고리 추가)으로 흡수하는 것도 검토할 만함.

### 3순위 — "지금 나가도 될까" (대기질 기반)
- **컨셉**: 현재 위치 대기질(PM2.5/PM10/오존) 기준 외출 적합도 + 마스크 필요 여부 안내
- **핵심 API**: 한국환경공단 에어코리아 대기오염정보
- **왜 좋은 후보인가**: 데이터 신선도 가장 좋음(시간단위), 로직 제일 단순(수치 구간별 룰).
- **리스크**: 단독 앱으로는 기능이 얇음(체감상 "위젯"급) — 독립 3탄보다는 1탄에 "오늘의 대기질" 카드 하나로 얹는 게 더 실용적일 수 있음. 개발계정 트래픽 500건 제한도 상용 서비스 규모에선 운영계정 전환 신청 필요.

## 확인 필요 사항 (다음 단계, 착수 전 실측 필수)
- 후보 API 3개 전부 **실제 활용신청 및 응답 필드 실측 검증 안 됨** (1탄/2탄 때처럼 Phase 0에서 실측 필요 — 지금은 검색 근거 기반 후보 제시 단계일 뿐)

- 순위 1(병원/약국)의 응급실 실시간 병상 API 존재 여부 미확인

## 2차 확장 조사 (카테고리 전수 스캔, 2026-08-29)

> 1차 조사가 "만복이 직감으로 고른 5개 도메인"만 본 것에 대한 바로보기님 지적("왜 5개밖에 안 되냐")에 따른 후속. data.go.kr 공식 대분류(16개: 공공행정·과학기술·교육·교통물류·국토관리·농축수산·문화관광·법률·보건의료·사회복지·산업고용·식품건강·재난안전·재정금융·통일외교안보·환경기상, [WebFetch](https://www.data.go.kr/tcs/dss/selectDataSetList.do)로 확인)를 기준으로, 1차에서 다룬 4개(보건의료/환경기상/교통물류/문화관광)를 제외한 나머지를 전수 확인.

### 신규 후보 발견 — 🆕 "지금 빈자리 있는 도서관/열람실" (교육 카테고리)
- **핵심 API**: 행정안전부 한국지역정보개발원_(전국 통합데이터) 공공도서관 열람실 실시간 정보 (`data.go.kr/data/15142580`) — 전국 통합, **실시간** 잔여좌석 수 제공. 성남시 등 개별 지자체도 유사 데이터 보유(도서관명/열람실명/총좌석수/현재이용/잔여좌석).
- **컨셉**: 위치+원하는 도보거리 입력 → 지금 빈자리 있는 도서관/열람실을 거리순+잔여좌석순으로 추천
- **왜 강한 후보인가**: 1차 TOP 3(병원/문화행사/대기질)보다 오히려 **"실시간성"과 "즉각적 의사결정" 적합도가 더 높음** — 병원은 운영시간이 정적 정보 위주였고 대기질은 앱으로는 얇았는데, 이건 "잔여좌석"이라는 순수 실시간 수치 하나로 핵심가치가 완성됨. 순수 규칙기반(거리+잔여좌석 정렬) 그 자체.
- **리스크**: 전국 통합 API의 실제 갱신주기 미실측(지자체별로 시스템이 달라 일부는 갱신 안 될 가능성), 활용신청/KOGL 라이선스 미확인.

### 확인했으나 후보에서 제외
| 카테고리 | 확인한 데이터 | 제외 사유 |
|---|---|---|
| 식품건강 | 식품안전나라 식중독 발생 통계 API | 연도/월별 집계 통계 위주, 실시간 상황판단용 아님 — "지금 갈만한 식당" 같은 상황추천엔 부적합, 굳이 쓴다면 1탄의 필터 옵션으로나 흡수 가능 |
| 농축수산 | 전국 공영도매시장 실시간 경매정보 (진짜 실시간, `data.go.kr/data/15141808`) | 데이터 자체는 실시간성 우수하나 타겟이 B2B(도매상/유통업자)라 우리 시리즈의 소비자 상황추천 패턴과 안 맞음 |
| 사회복지 | 어린이집 정보(한국사회보장정보원) | 정원 정보는 있으나 **실시간 이용가능 여부 데이터 확인 안 됨**(정적 정보 위주), 이미 "어린이집정보공개포털"이라는 전용 서비스가 존재해 차별화 어려움 |

### 확인 안 함(구조적으로 낮은 적합도로 판단, 검색 생략)
공공행정·과학기술·국토관리·법률·산업고용·재정금융·통일외교안보 — 성격상 실시간 상황판단형 데이터일 가능성이 낮아(행정통계/연구과제/부동산등기/법령/채용공고/시세지표/외교) 이번 조사에서는 스킵함. **단정은 아님 — 필요 시 재조사 대상.**

### 재순위 — 통합 TOP 4
1. **"지금 갈 수 있는 병원/약국"** (1차 1순위 유지 — 도메인 독립성, 리텐션 가치 최고)

3. **"오늘 뭐 볼까"(문화행사)** — 1탄과 자기잠식 우려는 여전히 유효, 3순위 유지
