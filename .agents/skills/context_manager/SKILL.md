# Context Manager Skill

## 용도
- 텅 빈 깡통 상태(Zero-context)에서 기획안을 작성하는 것을 방지.
- 사용자(바로보기님)의 과거 피드백이나 지시사항을 무조건 1순위로 고려해야 할 때 사용.

## 작동 절차
1. 만복이가 신규 업무를 할당받으면, 즉시 이 스킬을 호출합니다.
2. `D:\AI\AI_hub\shared\user_context\` 디렉토리 또는 로컬 DB에 저장된 사용자의 최근 선호도와 피드백 내역을 검색(`grep_search` 또는 문서 조회)합니다.
3. 검색된 과거의 문맥(Context)을 현재 기획안(Spec)에 융합하여, "사용자 맞춤형 기획"을 산출합니다.

## Eval 테스트 케이스
1. 사용자 과거 선호도 조회
2. 최근 지시사항 반영
3. 메모 검색 1
4. 메모 검색 2
5. 문맥 연계 답변 테스트

## 성공/실패 채점 기준
과거 메모(local_store.db)에서 사용자의 Context를 누락 없이 100% 불러와서 답변에 반영했는가?
(단, 위 기준의 달성 여부는 안티가 주관적으로 판단하지 않고, 반드시 `fact_checker.py` (Devil's Advocate) 스크립트를 통해 객관적으로 자동 채점하여 "최종판정: PASS"를 받아야만 5/5 통과로 인정됨)
