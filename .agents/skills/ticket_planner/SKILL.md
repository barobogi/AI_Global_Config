# Ticket Planner Skill

## 용도 (When to use)
- 사용자로부터 모호하거나 범위가 넓은 신규 기능, 스크립트 개발, 시스템 구축 지시를 받았을 때
- 코딩에 착수하기 전, 요구사항의 구멍(Edge cases)을 메우고 명확한 기획서(Spec)를 도출해야 할 때

## 작동 원리 및 수행 절차 (Steps)

1. **Grill (역면접 진행)**:
   - 사용자가 제공한 초기 기획이나 아이디어를 바탕으로 3~5가지 날카로운 질문(주요 기능, 예외처리, 외부 의존성, 인터페이스 등)을 생성하여 사용자에게 묻습니다.
   - 사용자(바로보기님)가 명확한 답변을 줄 때까지 절대 코딩이나 스크립트 작성을 시작하지 않습니다.

2. **To Spec & To Tickets (기획서 작성 및 티켓 분할)**:
   - 사용자의 답변이 완료되어 기획이 탄탄해지면, 동봉된 파이썬 스크립트(`scripts\ticket_splitter.py`)를 실행합니다.
   - 스크립트는 초기 기획과 답변을 분석하여 **명확한 스펙**과 **개발 단위 티켓(JSON)**으로 자동 분할합니다.

## 사용 방법
```bash
# 사용자의 초기 요구사항과 역면접을 통해 얻은 답변을 인자로 넘깁니다.
python D:\AI\.agents\skills\ticket_planner\scripts\ticket_splitter.py --prompt "초기 요구사항 요약" --answers "사용자 답변 내역 요약"
```

## 출력 형태
스크립트 실행 후 `tasks.json` 형태의 하위 작업 목록과 안티에게 지시할 수 있는 GPS(Goal, Proof, Steps) 구조를 얻을 수 있습니다. 이후 만복(Planner)은 안티(Operator)에게 각 티켓을 하나씩 개별적으로 지시하세요.
